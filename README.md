# Website-Profil-Dusun-Teluk-Lombok

## Struktur Proyek

- `index.html` - beranda website.
- `views/` - seluruh halaman HTML, termasuk detail potensi.
- `assets/` - logo, foto, peta, dan aset visual lokal.
- `styles/` - stylesheet halaman.
- `scripts/` - JavaScript untuk navigasi mobile, galeri, dan interaksi halaman.

Halaman sekunder diakses melalui file pada folder `views/`, misalnya
`/views/profil-dusun.html` dan `/views/potensi.html`.
